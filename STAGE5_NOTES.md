# Stage 5 — Search, filtering and navigation reliability

- Added bilingual stock-only and maximum-price filters, a clear-filters control, live result count, and empty-results state.
- Product search accepts English catalog names as well as Persian names.
- Corrected the mobile navigation toggle, including `aria-expanded` and closing after navigation.
- Re-render product results on language change.
- Existing 3D SVG backgrounds remain active throughout the site.

## Important limitations
This is still a static frontend demo. No live pharmacy stock, real payment, prescription processing, or AI provider is connected. Prices remain in the project's original Toman units; there is no fictitious exchange-rate conversion. Do not use the prescription form to collect real patient data without a secure backend and compliance review.
