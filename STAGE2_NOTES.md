# Stage 2 — Novin Daroo

## Implemented
- Expanded EN/FA phrase coverage for the homepage, navigation, chat labels and marketing sections.
- Language switching without a full page reload; HTML lang/dir and document title updated.
- Dynamic content observer for text added by the frontend.
- Refined responsive visual design, focus states, reduced-motion accessibility and RTL/LTR alignment.

## Important limitations
- This is a static frontend demo, not a live pharmacy, AI model or payment system.
- English translation is not yet comprehensive across all pages or dynamically generated catalog data.
- Do not upload real prescriptions or medical information to this demo.
- Production use requires backend validation, authentication, security review, real localization catalogs and regulated medical workflows.

## Run
Use a local static server: `python -m http.server 8000`, then open http://localhost:8000.
